# Estimación de tiempo para el Programa 1 (PSP0)

Para calcular el tiempo inicial se dividió el proyecto en tareas concretas y se comparó cada una con ejercicios previos de programación estructurada y manejo de listas. Como es la primera vez que se lleva el registro riguroso de tiempos con el proceso PSP0, se incluye un margen de contingencia del 10 % para absorber imprevistos en la toma de métricas y ajustes de compilación.

## Desglose de actividades estimadas

| Fase PSP0 | Actividad específica | Tiempo estimado (minutos) |
|---|---|---|
| Planificación | Lectura del kit de trabajo, aclaración de dudas, definición de requisitos y estimación | 30 |
| Diseño | Elaboración de pseudocódigo, traza de escritorio, diagramas SVG y estándar de código | 50 |
| Código | Implementación del nodo y la lista enlazada | 25 |
| Código | Implementación de la calculadora estadística (media y desviación) | 20 |
| Código | Implementación del lector de archivos y validación de líneas con cultura invariante | 25 |
| Código | Implementación de la interfaz de consola y el punto de entrada del programa | 20 |
| Compilación | Compilación con advertencias tratadas como errores hasta lograr cero fallos | 15 |
| Pruebas | Ejecución de casos de prueba manuales por consola y documentación de evidencias | 60 |
| Postmortem | Registro de métricas finales en el resumen del plan, conteo de líneas de código y propuesta PIP 1 | 25 |
| | **Subtotal de actividades** | **270** |
| | Margen de contingencia (10 %) | 30 |
| | **Tiempo total planeado** | **300** |

El tiempo estimado para el proyecto completo corresponde a 300 minutos (5 horas de trabajo). Esta cifra se ingresa como tiempo planeado global en la herramienta de seguimiento (PSP Tracker) antes de comenzar con la fase de diseño.
